# Workflow: new product (greenfield)

Use when nothing is built yet: the input is an idea, a client brief, notes from a meeting or a draft.

- **Inputs:** the brief and any draft documents, mockups or examples the user supplies. There is no repository to explore; skip Step 2 of the main process.
- **Focus of the questions:** who the users are, the one main flow that must work in the first version, and what is deliberately left out. A brief usually describes the solution; ask what problem it solves and for whom.
- **Scope:** keep the first version small. Put everything the brief mentions but the first version does not need into Out of Scope, so it is a decision rather than an omission.
- **Output:** a PRD for the whole product, `docs/PRD.md`.
